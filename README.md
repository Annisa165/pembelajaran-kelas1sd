# 🌟 Pembelajaran Kelas 1 SD
Website belajar sambil bermain untuk anak kelas 1 SD.

## 🚀 Cara Mengakses
### Online (lewat GitHub Pages)
Buka tautan berikut di browser:
👉 **https://annisa165.github.io/pembelajaran-kelas1sd/**

### Offline (dari file)
1. Unduh atau `clone` repository ini.
2. Buka file **`index.html`** dengan cara diklik dua kali, atau tarik ke jendela browser.
3. Web langsung bisa dipakai tanpa instalasi apa pun.

```bash
git clone https://github.com/annisa165/pembelajaran-kelas1sd.git
```
